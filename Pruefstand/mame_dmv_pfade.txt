# Welche Quelldateien das Verhalten der DMV in MAME bestimmen koennen.
#
# Wofuer das gebraucht wird: mame_holen.sh darf einen fertigen Bau aus
# einem Release-Anhang nehmen, auch wenn der Fork seither weitergegangen
# ist - aber nur, wenn KEINE dieser Dateien sich geaendert hat. Dann ist
# bewiesen, dass die DMV sich gleich verhaelt, und der Unterschied liegt
# woanders (in aller Regel in rfka01s Druckern, die nur deshalb
# mituebersetzt werden, weil die K210 einen Centronics-Anschluss hat).
#
# DIESE LISTE MUSS GEPFLEGT WERDEN. Wer im Treiber ein Geraet in Dienst
# nimmt, das hier nicht steht, traegt es im selben Commit ein. Sonst
# bliebe ein veralteter Anhang unbemerkt im Einsatz, und wir messen an
# einem Emulator, der nicht der ist, fuer den wir ihn halten.
#
# Im Zweifel aufnehmen. Ein Pfad zu viel kostet einen Bau, ein Pfad zu
# wenig kostet eine falsche Messung.
#
# Leerzeilen und alles ab # werden ueberlesen. Pfade ohne Entsprechung
# im Baum stoeren nicht.

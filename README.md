# DMV Firmware

New and modified firmware for the **NCR Decision Mate V** (DMV) · Neue und geänderte Firmware für die **NCR Decision Mate V**

| | |
|---|---|
| [`EXTKB/`](EXTKB/) | Extended firmware for the keyboard controller on the motherboard: key click on/off/faint tick, tick instead of the power-on beep while a key is held, three-voice synthesizer with noise, race benchmark – tested in MAME, not yet on real hardware · Erweiterte Firmware für den Tastaturcontroller auf dem Motherboard: Tastaturton an/aus/leiser Knack, Knack statt Einschaltpiep bei gehaltener Taste, dreistimmiger Synthesizer mit Rauschen, Rennwerk – in MAME getestet, auf echter Hardware noch nicht |
| [`Keyclick/`](Keyclick/) | Utility KEYCLICK ON/OFF/LOW for DOS, CP/M-80, CP/M-86 and CP/M-68K, needs EXTKB · Utility KEYCLICK ON/OFF/LOW für DOS, CP/M-80, CP/M-86 und CP/M-68K, braucht EXTKB |
| [`SYNDEMO/`](SYNDEMO/) | Synthesizer demo and programming interface for DOS, needs EXTKB · Synthesizer-Demo und Programmierschnittstelle für DOS, braucht EXTKB |
| [`DMVTRAK/`](DMVTRAK/) | MOD player and tracker for the DMV speaker (uses EXTKB) or a Covox Speech Thing on the K210 · MOD-Player und Tracker für den Lautsprecher der DMV (nutzt EXTKB) oder ein Covox Speech Thing an der K210 |
| [`K235FW/`](K235FW/) | Firmware 2.2 for the K235 and K235+ 16-bit modules: faster memory test up to 1 MB (K0815), monitor without password, terminal operation via K211 – tested in MAME, not yet on real hardware · Firmware 2.2 für die 16-Bit-Module K235 und K235+: schnellerer Speichertest bis 1 MB (K0815), Monitor ohne Passwort, Terminalbedienung über K211 – in MAME getestet, auf echter Hardware noch nicht |
